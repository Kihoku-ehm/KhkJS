# Rock-Paper-Scissors Game

## Overview
This project is a simple implementation of the classic game Rock-Paper-Scissors. It allows users to play against the computer by selecting one of the three options: rock, paper, or scissors. The game determines the winner based on the standard rules.

## Files
- `src/index.html`: Contains the HTML structure for the game, including buttons for user interaction and a display area for results.
- `src/styles.css`: Contains the CSS styles that enhance the visual appearance of the game.
- `src/app.js`: Contains the JavaScript logic that handles user input, generates computer choices, determines the winner, and updates the display.

## How to Play
1. Open the `index.html` file in a web browser.
2. Click on one of the buttons: Rock, Paper, or Scissors.
3. The computer will randomly select its choice.
4. The result will be displayed, indicating whether you won, lost, or tied.

## Setup
To run the game, simply open the `index.html` file in your preferred web browser. No additional setup is required.
